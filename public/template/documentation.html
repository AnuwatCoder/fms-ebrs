Liner — Bootstrap Admin Documentation

A complete guide to installing, customizing, and extending the Liner Bootstrap admin template. 60+ pre-built pages, dark mode, RTL, 5 color presets, and pixel-perfect design.

Introduction

Liner is a production-ready Bootstrap 5 admin template built with pure HTML, CSS, and vanilla JavaScript. No build step, no framework lock-in — just open the files and ship.

This Bootstrap version mirrors the React and Vue versions pixel-for-pixel, so you can switch stacks without redesigning. All features ship out of the box:

  • 60+ pages across dashboards, apps, UI elements, forms, tables, charts, and authentication
  • Dark / light mode with smooth transitions and persisted preference
  • 5 color presets — Navy, Blue, Emerald, Orange, Rose — switchable via the Settings Panel
  • RTL support using CSS logical properties
  • 3 layout modes — expanded sidebar, collapsed icon-only sidebar (with hover flyouts), and horizontal top-nav
  • ApexCharts integration for 6 chart types with theme-aware colors
  • Lucide icons — 1,000+ crisp SVG icons

Installation

Liner Bootstrap has zero build dependencies. You can use it three ways:

1. Drop into XAMPP / any local server

  1. Copy the template folder anywhere under your web root (e.g. htdocs/).
  2. Start XAMPP / Apache / nginx.
  3. Visit http://localhost/dashboard.html.

2. Direct file open

Most pages work by opening dashboard.html directly in a browser. A few features (font loading, SVG icons via CDN) work better over http:// than file://.

3. Deploy to static host

Upload the entire template folder to any static host — Netlify, GitHub Pages, Cloudflare Pages, S3, or your own server. No build required.

Tip: All CSS, JS, fonts, and chart libraries are loaded from public CDNs (jsDelivr, Google Fonts, simpleicons). For air-gapped deployments, mirror them locally and adjust the <link> and <script> tags in each page's <head>.

Folder Structure

The Bootstrap version is intentionally flat — every page is a top-level HTML file that links to shared assets.

./
├── assets/
│   ├── css/
│   │   └── theme.css      # Single stylesheet — all components, layouts, utilities
│   └── js/
│       └── app.js         # Theme manager, layout init, per-page handlers
├── img/
│   ├── avatars/           # User avatars used across pages
│   ├── unsplash/          # Cover images, product shots
│   ├── logo.svg
│   └── favicon.svg
├── dashboard.html          # Default landing — Modern dashboard
├── analytics.html
├── ecommerce.html
├── music.html
├── general.html
├── calendar.html · chat.html · email.html · ...   # 60+ pages total
└── documentation.html     # You are here

Each HTML page contains its sidebar, header, settings panel, and main content inline — there are no <iframe> includes. This makes pages independently deployable and easy to extract.

First Run

Open dashboard.html in a browser. You should see:

  • A vertical sidebar on the left with grouped menu items
  • A fixed top header with breadcrumb, search, dark-mode toggle, notifications, and settings gear
  • The main content area with stat cards and charts

Click the gear icon (top right) to open the Settings Panel, where you can switch color preset, dark mode, RTL, sidebar collapse, and horizontal layout. All preferences persist in localStorage.

HTML Structure

Every page follows the same skeleton:

<!DOCTYPE html>
<html lang="en">
<head>
  <!-- Page-specific title -->
  <title>Dashboard | Liner</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <link href="assets/css/theme.css" rel="stylesheet">
  <script src="assets/js/app.js"></script>
  <!-- Page slug — drives per-page JS routing -->
  <script>window.LINER_PAGE = 'dashboard.html';</script>
</head>
<body>
  <aside class="app-sidebar" data-sidebar>...</aside>
  <header class="app-header">...</header>
  <aside class="settings-panel">...</aside>
  <main class="app-main">
    <!-- Page content -->
  </main>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
  <script src="https://unpkg.com/lucide@latest"></script>
</body>
</html>

The four landmarks (.app-sidebar, .app-header, .settings-panel, .app-main) are required on every authenticated page. Auth pages (login, register, etc.) skip them.

theme.css

Everything visual lives in assets/css/theme.css: design tokens, Tailwind-compat utility classes, Bootstrap overrides, component styles, and page-specific blocks. The file is heavily commented and organized into sections.

Design tokens

Color presets are defined as CSS custom properties at the top of the file:

:root {
  --p-500:   0  66 118;    /* Default: Navy primary */
  --p-600:   0  56 102;
  --sidebar-w: 260px;
  --header-h:  64px;
}
html.preset-blue    { --p-500: 59 130 246; }
html.preset-emerald { --p-500: 16 185 129; }

To add your own brand color, add a new html.preset-{name} selector with --p-50 through --p-900 RGB triplets, then register it in the settings panel (see Color Presets).

app.js

The single app.js file is split into four parts:

  1. Theme manager — handles dark mode, color preset, RTL, and sidebar state with localStorage persistence.
  2. Menu definition — window.LINER_MENU drives the sidebar and horizontal menu.
  3. Chart helpers — LinerChartColors() and LinerApexBase() return theme-aware ApexCharts config.
  4. Per-page handlers — each page declares window.LINER_PAGE = 'foo.html' and the matching block runs its specific JS.

Per-page handlers follow this pattern:

if (window.LINER_PAGE === 'dashboard.html') {
  document.addEventListener('DOMContentLoaded', () => {
    const C = LinerChartColors();
    const B = LinerApexBase();
    // Build charts, attach event listeners, etc.
  });
}

Menu Configuration

The sidebar and horizontal menu are both generated from a single source: window.LINER_MENU in app.js. Each entry is a group with a group icon and an array of items:

window.LINER_MENU = [
  {
    group: 'Dashboards',
    groupIcon: 'layout-dashboard',
    items: [
      { label: 'Modern',    icon: 'layout-dashboard', path: 'dashboard.html' },
      { label: 'Analytics', icon: 'activity',         path: 'analytics.html' },
    ],
  },
  {
    group: 'Apps',
    groupIcon: 'layers',
    items: [
      { label: 'Blog', icon: 'book-open', children: [
        { label: 'Posts',  icon: 'book-open', path: 'blog-posts.html' },
        { label: 'Detail', icon: 'eye',       path: 'blog-detail.html' },
      ]},
    ],
  },
];

To add a new menu item: edit app.js, add an item to the appropriate group, and create the corresponding HTML page. The sidebar (expanded, collapsed, and horizontal modes) regenerates automatically.

Tip: Icons come from Lucide. Use the data-lucide="icon-name" attribute anywhere — the runtime converts them to inline SVG. Browse all icons at lucide.dev/icons.

Color Presets

Liner ships with five built-in presets. Switch them via the Settings Panel or programmatically:

LinerTheme.setColor('emerald');  // 'default' | 'blue' | 'emerald' | 'orange' | 'rose'

Add a custom preset

In theme.css, add a new html.preset-{name} { --p-50: r g b; ... --p-900: r g b; } rule (RGB triplets, space-separated, no rgb() wrapper). Then add a swatch button in the Settings Panel of each page (or extend the panel template).

Dark Mode

Dark mode is class-based — the root <html> element gets the dark class toggle. All component styles have dark variants via the html.dark .selector pattern in theme.css.

// Programmatic toggle
LinerTheme.toggleDark();

// Force a specific mode
LinerTheme.setDark(true);   // dark
LinerTheme.setDark(false);  // light

// Read current state
const isDark = LinerTheme.isDark;

The user's preference persists in localStorage under liner-theme and is restored on every page load before paint (prevents flash).

RTL Support

Right-to-left layouts are toggled by setting dir="rtl" on <html>. The stylesheet uses CSS logical properties (margin-inline-start, border-inline-end, inset-inline-start) so layouts mirror automatically.

LinerTheme.toggleRTL();
// or
document.documentElement.setAttribute('dir', 'rtl');

Sidebar Modes

Expanded (default)

Full 260px sidebar with group titles, icons, and labels. Items with children expand into nested submenus.

Collapsed (icon + label)

Toggled by clicking the menu icon in the header. Shows one icon-per-group with the group name as a small label. Hovering a group reveals a flyout dropdown containing all items, including nested children grouped by sub-headers.

LinerTheme.toggleCollapsed();

Mobile drawer

Below 992px the sidebar slides off-screen and the hamburger icon in the header opens it as an overlay. Backdrop click or link click closes it.

Horizontal Layout

Switches the navigation from the left sidebar to a top horizontal bar. Useful for content-heavy dashboards or marketing-style admin views.

LinerTheme.toggleHorizontal();

When active, body.horizontal-mode is set. The sidebar is hidden on desktop and replaced by a top bar generated from the same window.LINER_MENU. Hover any group to reveal its dropdown. On mobile, the horizontal bar is hidden and the sidebar drawer takes over.

Charts

Charts use ApexCharts with theme-aware colors. Every chart picks up the current color preset, dark mode, and axis/grid colors automatically.

const C = LinerChartColors();   // { primary, cyan, emerald, amber, rose, violet, grid, axis, text, bg }
const B = LinerApexBase();      // Defaults: fontFamily, toolbar off, grid colors, etc.

new ApexCharts(document.querySelector('#my-chart'), {
  ...B,
  chart: { ...B.chart, type: 'line', height: 280 },
  series: [{ name: 'Sales', data: [10, 20, 30, 40] }],
  colors: [C.primary],
}).render();

Six dedicated pages: line-chart.html, area-chart.html, bar-chart.html, column-chart.html, donut-chart.html, radialbar-chart.html — each with 4–6 chart variants plus mini KPI sparklines.

Icons

Liner uses Lucide. To render an icon, drop in:

<i data-lucide="calendar" class="lucide-md"></i>

The Lucide runtime (loaded via CDN) converts each <i> into an inline SVG. Available size classes: .lucide-xxs (10px), .lucide-xs (12px), .lucide-sm (14px), .lucide-md (18px), .lucide-lg (22px), .lucide-xl (28px). Color the icon with any text-color utility — .text-primary-500, .text-emerald-600, etc.

If you swap an icon dynamically via JS (e.g. eye → eye-off for password fields), call lucide.createIcons() to re-render.

Add a New Page

Five steps to add my-page.html:

  1. Copy an existing page (e.g. dashboard.html) and rename it to my-page.html.
  2. Update <title> and the window.LINER_PAGE slug to 'my-page.html'.
  3. Replace the content inside <main class="app-main">...</main>.
  4. Register the page in window.LINER_MENU (in app.js) so it shows up in the sidebar.
  5. Optional: add a per-page JS block in app.js: 
    if (window.LINER_PAGE === 'my-page.html') {
  document.addEventListener('DOMContentLoaded', () => {
    // Your page-specific JS
  });
}

The active sidebar link is auto-detected from window.location.pathname, and breadcrumbs are inferred from the title.
